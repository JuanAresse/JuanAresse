# Hola, soy Juan Arese

[English](README.md)

Desarrollo software y enfoco mi trabajo en la ingeniería de inteligencia artificial aplicada: conectar modelos, datos y herramientas para construir aplicaciones útiles y automatizar procesos.

Me interesa transformar una necesidad concreta en una solución que pueda probarse y mantenerse, desde la preparación de la información y el desarrollo de APIs hasta la evaluación y el despliegue.

## Áreas de enfoque

- **Aplicaciones con LLMs:** procesamiento de información y generación de respuestas con contexto.
- **Agentes de IA:** integración de herramientas, ejecución de tareas y supervisión humana.
- **RAG y búsqueda:** recuperación de información sobre documentos y fuentes de conocimiento.
- **Automatización:** conexión de servicios, validación de datos y reducción de tareas manuales.
- **Calidad:** pruebas, trazabilidad, evaluación y manejo de errores.

## Proyectos de software

### [SUC — Sistema Unificado de Consultas](https://github.com/JuanAresse/suc)

Tesis individual desarrollada con Python, FastAPI y SQLite para integrar información social de múltiples fuentes, validar importaciones y generar consultas y reportes trazables.

### [Padilla Contratos](https://github.com/JuanAresse/padilla-contratos)

Aplicación para digitalizar la recopilación de información y la generación de documentación contractual, con formularios, validaciones y procesamiento documental.

### [The Maze](https://github.com/JuanAresse/The-Maze)

Videojuego desarrollado íntegramente por mí con Unity y C#, con generación procedural de laberintos y un sistema de programación visual de movimientos.
